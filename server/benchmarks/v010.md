# AegisX 0.10 · transport and 395M research evidence

**The Nginx performance gap is not closed.** This release improves transport behavior and admission accounting, with small measured forwarding gains. It does not justify Nginx parity, enterprise readiness, general memory reduction or a universally faster proxy claim.

## Delivered runtime

One Linux executable, 45,080,232 bytes, SHA-256 `8475caf71cbddbd7d9a8fe4ca41af1995c369ec25fc25cdfc8c354fe8fc39052`. Rust 1.98.1 is pinned from both repository root and server/. Standard Linux C/C++ runtime libraries are still required. The Next.js panel and the existing 895,178-parameter UINT8 model remain embedded. The research 395M checkpoint is not embedded.

- Exact atomic global admission accounting replaces the uncontended semaphore path. Resource-release notifications preserve cancellation recovery and the configured global bound. Waiting remains finite and deadline-bound; strict FIFO is not promised.
- Upstream active/latency bookkeeping is skipped only when the control plane, balancing policy and configured capacity do not require it. Explicit capacity limits and adaptive/least-active policies retain the necessary state.
- The pinned Pingora Core patch flushes every already-ready HTTP response batch. A bounded 4 KiB default writer can coalesce ready header/body writes without waiting for future streaming chunks. A single body in a batch avoids an intermediate copy. Flush state survives cancellation; write timeouts remain enforced. Lua can set write_buffer_bytes=0.
- The Pingora Timeout patch removes one redundant Box around an already-boxed future. Timeout semantics are unchanged.
- These are two vendored dependencies, not extra application crates or processes. The Cargo workspace uses one lockfile. Original source hashes, Apache-2.0 licenses and patch notices are retained under server/vendor and distributed notices under dist/.

SQLite remains authoritative for decisions, with coherent caches. Inference remains post-completion background work. Forwarded requests are not aborted by late model verdicts. Parser, framing, trust, TLS verification and body limits are not bypassed to improve throughput.

## Paired forwarding measurement

[Complete trials and raw wrk output](v010-nginx.json). Installed Nginx **1.24.0**, WSL loopback, i5-10210U, eight workers for both proxies, two native-backend workers, two wrk threads, HTTP/1.1 keepalive, 128-byte bodies. Four 12-second measurements per target and connection count, two-second warmups, rotating order balanced over all four targets. Every request reaches the backend; no response cache, capture, inference or rate policy. AegisX retains correlation/forwarding headers and admission machinery; this is not identical feature work. Nginx request and response buffering are off. Candidate write buffer is 4096; preserved 0.9 baseline is 0.

No own build, training, test or profiling job ran concurrently. Other host workloads, thermal state and scheduling are uncontrolled. The direct-backend median is 183,766/s at 128 connections and 175,675/s at 256; its substantial between-trial variation limits conclusions. No HTTP or socket errors were reported.

| Connections | 0.9 req/s | 0.10 req/s | Change in medians | Nginx req/s | 0.10 / Nginx |
| --- | ---: | ---: | ---: | ---: | ---: |
| 128 | 30,724.67 | 32,474.08 | +5.69% | 77,971.53 | 41.65% |
| 256 | 28,166.08 | 28,928.37 | +2.71% | 66,286.54 | 43.64% |

| Connections | 0.9 CPU microseconds/request | 0.10 CPU microseconds/request | Nginx CPU microseconds/request |
| --- | ---: | ---: | ---: |
| 128 | 167.61 | 161.97 | 50.44 |
| 256 | 176.62 | 163.15 | 55.23 |

CPU time includes user and kernel time for the measured proxy and its child workers. The measured reductions in median CPU/request are 3.37% and 7.62%. This is a whole-change comparison, not proof of a single patch's contribution. One paired 128-connection trial regressed from 31,528/s to 28,437/s; all observations remain in the report.

Median PSS increased slightly: 72,979,456 → 73,571,840 bytes at 128 connections and 84,650,496 → 86,093,824 at 256. There is **no general memory reduction claim**. PSS accounts for shared pages more usefully than adding worker RSS values.

The earlier buffering-only [preview](batch-preview.json) did not establish a speedup. The [capacity preview](capacity-preview.json) was also variable, including a substantial adverse trial. They are retained, not discarded. Initial CPU profiling identified allocation/copy and pooled-connection/task paths, but lost 16.9% of samples; it is directional evidence only, not a reliable causal breakdown of the entire Nginx gap.

The remaining performance work requires controlled kernel/user CPU profiling and connection/task allocation analysis, followed by repeated realistic workloads. SIMD, arenas or removing safety checks without such evidence is not a demonstrated solution.

## Policy workload

The separate [policy profile](v010-policy.json) enables SQLite-backed decision caching and rolling rate context, with capture and inference off. It uses two workers, 128 connections, four alternating 10-second trials and write_buffer_bytes=0 for both binaries. The measured median is **10,968.06/s for 0.9 and 10,693.89/s for 0.10 (−2.50%)**. Individual changes range from a gain to a substantial regression; there is no established improvement in this profile. No HTTP/socket errors occurred. It is different work from the forwarding/Nginx table and must not be conflated with it.

## Verification

- 28 application Rust tests pass on the pinned release compiler; Clippy passes with --no-deps and warnings denied for application code.
- 36 Python tests pass; Ruff passes. All 3,072 legacy transaction fixtures and 672 new retry fixtures reproduce their recorded rows exactly after separating their generators.
- 67 final-binary HTTP/TLS/storage/queue/model/control/package tests pass. Delayed Content-Length and chunked streaming tests coordinate backend progress with actual client reads.
- 334 scoped Pingora HTTP/1 unit tests and 17 timeout tests pass, including new header/non-final batch flush and cancellation/resume tests. These dependency unit tests ran on Rust 1.98.0; application tests, release build and end-to-end tests use 1.98.1.
- A broad upstream 607-test suite was attempted, encountered fixture/external-service-dependent failures and was interrupted; it is **not claimed as passing**. The scoped dependency tests and AegisX's own TLS/end-to-end fixtures provide the relevant validation. Upstream Clippy has an existing manual_is_multiple_of lint; application Clippy uses --no-deps rather than changing unrelated upstream code.
- Next.js static build and relocation test pass. [Real 0.9 → 0.10 upgrade](v010-upgrade.json) preserves an existing committed ban and old request events.

Project checks total 131; scoped dependency checks add 351. Test counts describe the stated suites, not production reliability guarantees. Git was read-only; no system Nginx service was changed.

## Model research

The [395,011,458-parameter ModernBERT-large experiment](../../model/research/unified-v2.md) completed 192 real optimizer updates, including 32 full-network updates. First and last pretrained layers changed, verified against the original checkpoint. It used 768 sample presentations and 652 distinct training rows from an 8,672-row prepared corpus, not a full corpus epoch.

Selected validation recall is 81.25% for content and 34.375% for journey violations, each with 0/32 observed benign false positives. The candidate fails the 90% prerequisite; final calibration/test scoring was not consumed. It is saved for research and does not replace the embedded compact model. No fast 395M runtime, ONNX parity, quantization, independent production generalization or zero-error claim is made.
