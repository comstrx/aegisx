# v0.3 performance evidence · 2026-10-01

Final binary SHA-256: afcaf0e54ff5a2ba76ec53b688a89e56c9edf61841c2fac4c9b74a525cb67f5e.

Local WSL loopback measurements, with Python client and origin sharing the same machine. No AegisX build, training or browser QA ran concurrently. The host is not isolated, results varied materially between runs, and the first baseline trial was notably slower. These are reproducible local observations, not production capacity or a universal speedup.

## Baseline comparison

[All raw trials](2026-10-01-v03.json): v0.2 vs final v0.3; 3 alternating trials/mode, 60,000 measured requests +512 warmup,16 clients,128-byte responses,2 proxy workers,model off. Storage queue65,536,retention1,000,000.

| Mode | v0.2 median requests/s | v0.3 median requests/s | v0.2 p95 | v0.3 p95 |
| --- | ---: | ---: | ---: | ---: |
| Forwarding, capture off | 27,407 | 28,697 | 0.983 ms | 0.952 ms |
| Full capture under saturation | 15,508 | 11,358 | 1.703 ms | 2.318 ms |

The +4.7% raw forwarding median is within substantial observed host variability; no reliable general speedup is established. Removing unused identity/decision work from pure mode recovered the earlier measured regression.

Full capture is approximately **26.8% slower** in this run. v0.3 adds opaque actor metadata and other telemetry work; it does not persist equivalent event payloads to v0.2. Both versions drop events under this load:

- v0.2:252,225 /236,773 /237,159 dropped events per trial.
- v0.3:223,539 /206,930 /261,252 dropped events per trial.

These throughput figures do not represent complete persisted journeys. The full-capture cost remains a constraint. Dropped counts include warmup and count events, not unique requests.

Earlier measurements are retained: [before encoding optimization](2026-10-01-v03-before-encoding.json), [before pure-path optimization](2026-10-01-v03-before-fastpath.json). Do not compare isolated runs as controlled causal proof: changed code and variable host conditions both contribute.

## Public-response cache

[Raw cache trials](2026-10-01-cache.json): final v0.3,3 alternating trials,10,000 measured GETs +512 warmup,16 clients,one public key,origin configured with a2ms async delay,model/capture off.

| Metric | Cache off | Cache on |
| --- | ---: | ---: |
| Median requests/s | 3,749 | 34,430 |
| Median p95 | 6.124 ms | 0.757 ms |
| Origin calls including warmup | 10,512 | 16 |

All trials showed the same origin-call reduction. The16 calls are initial concurrent misses; misses are not coalesced. This demonstrates the value of a warmed cache on eligible repetitive public content. It is **not** a9× speed claim for arbitrary applications, personalized responses, cold traffic or TLS. [Earlier cache trial](2026-10-01-cache-before-fastpath.json) remains available; substantial variance is visible.

## Capture controls

[Raw telemetry trials](2026-10-01-telemetry.json): final v0.3,3 alternating trials,20,000 requests +512 warmup,16 clients,immediate origin,model off.

| Capture mode | Median requests/s | Median p95 | Dropped events |
| --- | ---: | ---: | --- |
| Full | 10,445 | 2.697 ms | 12,157 /47,005 /20,146 |
| Summary | 11,743 | 2.086 ms | 0 /0 /0 |
| Summary, every tenth request | 12,635 | 1.971 ms | 0 /0 /0 |

Summary omits intermediate stages. Sampling omits nine out of ten journeys while enforcement/history remain active for every applicable request. Lower work and lower coverage are an explicit tradeoff. Zero drops in these bounded short runs does not prove sustainable lossless capture; the large queue can absorb a burst and drain at shutdown.

## Reproduce

From the repository root, after building; do not run these alongside compilers/training:

```sh
python3 server/tests/benchmark.py --baseline tmp/baseline/aegisx-v0.2 --current dist/aegisx --requests 60000 --output server/benchmarks/local-proxy.json
python3 server/tests/cache_benchmark.py --binary dist/aegisx --output server/benchmarks/local-cache.json
python3 server/tests/telemetry_benchmark.py --binary dist/aegisx --output server/benchmarks/local-telemetry.json
```

These tests do not establish real attack detection, WAN/TLS performance, durable action delivery, long-stream behavior or NGINX/Caddy parity.
